# MockMate

**MockMate** is an AI-powered mock interview platform that helps job seekers practice and improve their interview skills. Generate role-specific interview questions, optionally upload your resume for tailored questions and a fit analysis, answer with voice or text, and receive instant, personalized feedback with visual performance analytics.

Built with Next.js, Tailwind CSS, MongoDB, and the Google Gemini API.

## Features

- **AI-driven interviews** — role-specific questions and model answers generated by AI.
- **Resume-tailored questions** — optionally upload your resume (PDF); the AI reads it, tailors questions to your real background, and produces a resume-vs-role fit analysis highlighting strengths and gaps.
- **Voice answers** — record spoken answers that are transcribed automatically.
- **Instant feedback** — each answer is rated out of 10 with actionable, written feedback.
- **Visual analytics** — an overall score gauge, per-question rating chart, and a summary table give a clear picture of your performance.
- **Personalized experience** — questions adapt to job role, description, and experience level.
- **History** — revisit your previous mock interviews and feedback any time.

## Tech Stack

- **Next.js** — React framework for server-rendered and static web applications.
- **Tailwind CSS** — utility-first styling with a glassmorphism design system.
- **MongoDB (Mongoose)** — document database for interviews, questions, answers, and feedback.
- **Google Gemini API** — powers question generation, resume analysis, feedback, and audio transcription.
- **Clerk** — authentication and user management.
- **Recharts** — feedback visualizations.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/chiragattri305/mockmate.git
   ```

2. Navigate to the project directory:
   ```bash
   cd mockmate
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Create a `.env` file in the project root (see `.env.example`) and add your keys:
   ```env
   MONGODB_URI=your_mongodb_connection_string
   GEMINI_API_KEY=your_gemini_api_key
   NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_clerk_publishable_key
   CLERK_SECRET_KEY=your_clerk_secret_key
   ```

5. (Optional) Seed starter practice courses:
   ```bash
   npm run db:seed
   ```

6. Start the development server:
   ```bash
   npm run dev
   ```

7. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Usage

- **Create an account** — sign up to start your mock interview sessions.
- **Start an interview** — enter a job role, description, and experience level. Optionally upload your resume for tailored questions and a fit analysis.
- **Answer questions** — respond by typing or recording your voice.
- **Get feedback** — after the interview, review ratings, written feedback, and visual analytics.
- **Review history** — access previous interviews from the dashboard at any time.

## Environment Variables

| Variable | Description |
| --- | --- |
| `MONGODB_URI` | MongoDB connection string |
| `GEMINI_API_KEY` | Google Gemini API key |
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | Clerk publishable key |
| `CLERK_SECRET_KEY` | Clerk secret key |
| `NEXT_PUBLIC_INFORMATION` | Optional info note shown before an interview |
| `NEXT_PUBLIC_QUESTION_NOTE` | Optional note shown during questions |
